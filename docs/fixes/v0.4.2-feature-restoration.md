# v0.4.2：恢复 v0.4.0 全部功能，并保留内存修复

v0.4.1 错误地使用较早的功能基线，移除了 v0.4.0 的部分新增功能和修正。
这不是用户要求的行为。v0.4.2 恢复 `b1203356eadd017e3de57515690b41907c0403ba`
相对 `c521a92` 的全部业务代码与配套测试，保留 v0.4.1 的 AnyTLS 内存、
连接清理、LinkManager 死锁和会话 Content 并发修复。

恢复内容：

- observation 访问目标元数据上报、auto-v2 能力声明、节点 ApiKey 请求头认证。
- 全用户模式、旧版白名单兼容、暂停采集时保留认证限制。
- 重试队列、稳定事件 ID、无效事件隔离。
- 空用户列表撤销、无符合条件用户时专用节点保持运行。
- RouteOnly 嗅探，不用嗅探域名替换代理链实际目标。
- 对应配置解析、API、控制器、分发器与文档和测试。

人数、流量、原有 sensitive audit、DDNS、墙检测、多节点路由等功能未删减。
本次不改面板接口、不变更已有 observation 开关或上报语义。

对恢复文件逐文件与 v0.4.0 比较。唯一与内存修复共享的
`core/app/dispatcher/default.go`，相对 v0.4.0 只保留两个 LinkManager
LoadOrStore 修改；其余恢复文件字节一致。Xray 内存修复实现保持不变。
